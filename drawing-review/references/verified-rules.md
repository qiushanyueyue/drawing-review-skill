## V1 混凝土最低强度等级（rule: `C6-V1`）

- **依据**：GB 55008-2021《混凝土结构通用规范》第 2.0.2 条（强制性条文）。核对方式：对照规范原页逐项核对 C20/C25/C30/C40 数值与适用对象（2026-10-26）。
- **输入**（只取图纸明确写出的）：
  1. 设计说明“混凝土强度等级”中的“部位：C××”（必需）。
  2. 设计工作年限（等级恰好等于基准值时必需）。
  3. 抗震等级（钢筋混凝土构件等级低于 C30 时必需）。
  4. 全文是否出现“预应力混凝土/预应力梁、板/先张/后张/无粘结预应力”、“组合结构/型钢混凝土/钢管混凝土”、500 MPa 级钢筋（HRB500、HRBF500、HRB600 等）。

- **50 年基准值**：

| 构件类别 | 最低等级 |
|---|---|
| 素混凝土构件 | C20 |
| 钢筋混凝土构件 | C25 |
| 预应力混凝土楼板 | C30 |
| 其他预应力混凝土构件 | C40 |
| 钢-混凝土组合构件 | C30 |

- **钢筋混凝土加严**：承受重复荷载、抗震等级不低于二级、或采用 500 MPa 及以上钢筋时，不低于 C30。
- **设计工作年限大于 50 年**：最低等级应比上表提高（条文未给出提高幅度，本规则只判断是否**高于**基准值）。

- **判定逻辑**：
  1. 按部位名字面判断构件类别。只写构件名（板/墙/柱/梁等）且全文没有预应力、组合结构字样时按钢筋混凝土判断，并在 `basis` 注明“构件类别图纸未写明，暂按钢筋混凝土判断”。
  2. 部位是垫层、回填、找坡层等，或部位不明 → `needs_context`（条文说明：素混凝土结构一般不包含地下结构的素混凝土垫层）。
  3. 全文出现预应力/组合结构但没有关联到该构件 → `missing` 写“预应力或组合结构的适用部位未明确关联到该构件”。“预应力钢棒”“预应力锚索”不是预应力混凝土构件，不据此判断。
  4. 抗震等级为特一级、一级、二级 → 钢筋混凝土要求提到 C30。
  5. 全文出现 500 MPa 钢筋但未关联到构件 → `missing` 写“500MPa 级钢筋是否用于该构件未明确关联”。
  6. 等级低于 C30 且要求尚未到 C30：抗震等级未知 → 缺“抗震等级”；始终缺“是否承受重复荷载”。
  7. 设计工作年限出现多个不同值 → 缺“设计工作年限”。
  8. 结论：
     - 等级 < 要求值 → `suspected`（severity `high`），`problem` 写“采用 C×，低于 GB 55008-2021 第 2.0.2 条对××构件的最低要求 C×”。
     - 等级 = 基准值，且年限 > 50 年 → `suspected`（应比基准值提高）；年限未写明 → `needs_context`。
     - 满足已知条件但 `missing` 非空 → `needs_context`。
     - 都满足 → 仍为 `needs_context`（规则待专业审核，不能写“符合”）。一般不必写进报告，除非用户要求列出全部比对。
  9. 参数来自扫描/OCR 文字 → `needs_context`，注明须回原图核实。
- **不覆盖**：表格和图面中标注的强度等级（只读设计说明文字）；构件是否承受重复荷载；耐久性环境类别对强度等级的要求（GB 50010/GB/T 50476 另有规定，未纳入本规则）。
