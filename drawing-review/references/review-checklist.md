# 审查检查项

C1–C9 口径经真实施工图调试；C10–C15 为图面、计算书、勘察报告交叉复核的检查方向，尚未在真实样本上量化误报率，宁可降为“需补充条件”。每项写明**查什么、怎么判、什么情况不报**。`rule` 字段填检查项编号（如 `C2`）。

结论分级（详见 report-format.md）：`suspected` 疑似问题 / `needs_context` 需补充条件 / `not_checked` 未检查。

---

## C1 设计说明内部参数一致性（R03/R09/R11-1）

**查**：同一份说明内、或说明与图面之间，以下参数对**同一部位**前后写法不一致：混凝土强度等级、抗渗等级、保护层厚度、环境类别、抗震等级、钢筋牌号、设计使用年限、结构安全等级、荷载取值、地下水位/抗浮水位、防火等级。

**判**：两处引文都明确指向同一部位（部位名字面一致，或同一条款的上下文明确）→ `suspected`。

**不报 / 降级**：
- 部位名是组合（“顶板、底板及侧墙”）而另一处是单个构件 → 可以报，但在 `problem` 写清“组合条目与单项条目”，并在 `missing` 说明需确认适用范围；只有一方是组合且无法确认覆盖关系时用 `needs_context`。
- 不同部位、不同构件、不同工况、不同施工阶段取值不同是正常的。
- 两处可能分属不同设计阶段或不同子项（不同图纸的说明）→ `needs_context`。

## C2 构件在不同图中前后一致（R07/R11-2）

**查**：同一构件编号（KL、ZTL、KZ、Q、LL 等）在平面、剖面、详图、配筋表中的截面、配筋、标高、尺寸、跨数矛盾。

**判**：只有能证明两处是**同一构件同一字段**才比较：同一编号 + 同一图张/楼层/区域明确，或有显式详图索引（“详见 X 图”）。截面没有单位来源、钢筋等级未知时不比较截面/等级。

**不报 / 降级**：仅编号相同但楼层、区域不明 → `needs_context`；文字只是位置相邻（PDF 抽取顺序≠版面位置），除非标签和取值在同一行文字内，否则不当作对应关系。

## C3 防水与地下工程做法一致（R11-3）

**查**：防水等级、设防做法、混凝土抗渗等级、变形缝/施工缝/后浇带做法、外包防水层材料与厚度在不同说明或图中互相矛盾。

**不报**：只写了“按某图集”而另一处写具体做法、二者不冲突的；凭记忆认为“某等级应设几道防水”但图纸内没有相反文字的（这属于规范判定，需走 C6/已核对规则）。

## C4 表达与书写错误（R04/R11-4）

**查**：
- 配筋写法明显错误（如钢筋等级符号缺失、“@”位置错、直径与间距颠倒、数量级错误如“间距 2000mm 的箍筋”）。
- 单位错误：保护层、厚度等写成 `m` 而上下文明显是毫米（`mm`、`cm` 正常不报）。
- 标点：重复标点（“。。”“，，”）、括号不配对、重复词（“的的”）。
- 明显错别字：同音/形近字写错，或多字、少字。

**不报**：
- 全角/半角括号混用、中文句中的半角逗号/分号/冒号——只算排版瑕疵，不计问题。
- 构件名与方位词连写不是重字：“站台板板下”“顶板板面”“楼层层高”“墙墙顶”。
- 专业术语、构件名、规范编号、图号、数字本身；扫描/OCR 得到的文字（多为识别错误）。

## C5 引用错误（R01/R11-5）

**查**：图集号、规范号、页码、详图号、索引图号明显写错或前后不一。规范/图集引用的版本（年号）：
1. 列出说明中出现的每个标准编号 + 年号。
2. **能联网时**到官方来源核实状态（全国标准信息公共服务平台 std.samr.gov.cn、住建部标准公告、国家建筑标准设计网）。核实为废止/被替代 → `suspected`，写清替代标准与来源链接。
3. 不能联网或查不到 → `needs_context`，写“版本状态未核实”。**不要凭记忆判定现行或废止**。
4. 引用没有年号 → `needs_context`，建议补全年号（可列出同系列已知版本供选择，但不说哪个现行，除非已核实）。
5. `verified-rules.md` 里已核实的替代关系可直接使用，仍注明核对日期。

**注意**：同一编号在说明里出现多次只报一条，列出全部位置。地方标准只有在图纸本身写明工程地区时才作为依据，不跨地区套用。

## C6 已核对的规范数值规则（R06/R10）

只执行 `verified-rules.md` 中列出的规则（目前：混凝土最低强度等级，GB 55008-2021 第 2.0.2 条）。按规则写明的输入、判定逻辑、例外执行，缺前提就 `needs_context`。

对图纸中**其他**设计参数（保护层、裂缝宽度、最小配筋率、锚固长度等）：可以列为 `not_checked`“该参数未与规范比对”，或在 `suggestion` 里提示“相关条文候选：GB xxxx 第 x.x.x 条（待核对）”，**不得**给出“不满足规范”的结论。

## C7 说明条目编号与版面完整性（R08）

**查**：同一页同一栏、同一编号样式的条目编号重复、倒序、缺号（如 1、2、4）；跨页续接的编号断档（同一说明系列相邻页）。

**不报 / 降级**：章节号、小数编号、跨栏或编号重置的不当作同一序列；抽取的块顺序混乱、无法确认版面顺序时不报缺号；页面尺寸不同只作为限制说明，不判断图幅错误。

## C8 跨页参数矛盾（R11 跨图）

第二遍：把第 2 步抽取的参数（部位、参数、取值、引文）放在一起比对。只报“同一对象、同一参数、取值确实矛盾”，引文至少两条且来自不同页。判定口径同 C1。

## C9 同一份图纸内自相矛盾的说明语句（R11-6）

**查**：前后两条说明在做法、顺序、要求上直接冲突（如一处“先施作防水层后回填”，另一处“回填后施作防水层”）。

---

以下 C10–C15 针对图纸图面、计算书、勘察报告之间的对应关系。共同前提：**先确认是同一对象**（同一结构/出入口/区段、同一断面或构件编号、同一施工阶段或工况），在 `object` 写清对象，`object_match` 写 `explicit` 并在 `basis` 说明依据（相同剖切号、详图索引、计算书写明“对应××图××断面”等）。对应关系只是推断时写 `inferred`，结论只能是 `needs_context`。

## C10 图纸几何与标高一致

**查**：同一断面/构件在平面、剖面、详图之间的厚度、宽度、标高、轴线定位、支撑/锚杆道数与间距写法矛盾。

**判**：两处都有明确的对象标识（剖切号、构件编号、轴线），且是同一参数（如“顶板厚度”对“顶板厚度”）。

**不报 / 降级**：只能从图形量取、没有标注文字的尺寸（文字模式下不判断几何）；不同施工阶段、变截面处、加腋处取值不同；图像模式下看到但文字层里没有的数值 → `needs_context`，写明须回原图核实。

## C11 配筋表达与一致性

**查**：同一构件同一位置的钢筋直径、间距、根数、层数、方向（上/下层、内/外侧、纵/横向）在平面配筋图、剖面、配筋表、说明之间矛盾；附加筋、通长筋、加强区范围前后不一。

**判**：必须能确定标注属于哪个构件、哪一侧、哪一方向（同一行文字内写明，或 `near`/图像能看出引出线直接指向该构件且无其他候选）。

**不报 / 降级**：标注归属不明（附近有多个构件）、只靠位置相邻推断 → 不比较或 `needs_context`；“双层双向”“详见××”等写法与具体标注不冲突时不报。钢筋强度等级符号在 PDF 中常丢失（“Φ”“C”混用），只有字面明确时才比较等级。

## C12 计算书与图纸对应（模型一致性）

**查**：同一断面/构件在计算书中采用的截面尺寸、混凝土等级、钢筋、荷载（覆土、超载、水压）、地下水位/抗浮水位、支撑道数与位置、计算跨度与图纸不一致；计算书结论配筋大于图纸实配。

**判**：计算书写明对应的图纸断面/构件，或断面名称、编号与图纸完全一致；比较的是同一参数同一工况。实配与计算需要的比较，用 `calc` 换算到同一单位（如 `As_s(25,150)` 得 mm²/m）。

**不报 / 降级**：计算书只写“标准断面”“典型断面”而图纸有多个断面 → `needs_context`；计算采用偏保守取值（荷载更大、水位更高）不当作矛盾，除非用户要求列出；单位不明的不比较。

## C13 勘察参数与设计取值对应

**查**：计算书或设计说明声明“采用勘察报告建议值”的地层参数（重度、黏聚力、内摩擦角、基床系数、渗透系数、承载力特征值、地下水位）与勘察报告对应地层的建议值不一致；地层编号、名称对不上。

**判**：同一地层编号/名称、同一参数，且设计文件明确说采用勘察建议值。设计人员有意调整的（写明折减或经验取值）不报。

**不报 / 降级**：勘察报告给出范围值而设计取其中一个值；钻孔不同、区段不同；设计未声明取值来源 → `needs_context`。

## C14 计算书算式复算

**查**：计算书中写出的算式代入值与结果不符、前后转抄数值不一致、单位换算错误（kN 与 N、kPa 与 kN/m²、m 与 mm）。

**判**：用 `calc` 按计算书**自己写出的**公式和代入值复算，`calculation` 填 `expr`（复算式）和 `stated`（文件中的结果），默认相对偏差超过 1% 才算不符（四舍五入、取整可放宽 `tolerance`）。`verify` 会重算：复算与文件一致时问题自动降为线索。

**不报**：公式选择、计算模型、软件输出内部过程（只给结果没有算式的）；需要外部参数才能复算的。不评价“这个公式是否适用”，那属于规范判定。

## C15 施工阶段与工况对应

**查**：图纸的施工步序（分步开挖、架设/拆除支撑、换撑、结构形成）与计算书的计算工况明显缺项或顺序矛盾，如图纸有“第三道支撑”而计算书各工况均未出现，或拆撑顺序前后矛盾。

**判**：两份文件都写明了步序或工况列表，且属于同一断面/区段。

**不报 / 降级**：计算书只列控制工况（可能有意省略非控制工况）→ `needs_context`，写“需确认是否已验算该阶段”；不判断工况是否“足够”。

## 各专业关注点（只作为 C1–C9 的检查方向，不是规范判定）

| 专业 | 优先核对 |
|---|---|
| 结构 | 混凝土/钢筋等级、抗震等级、保护层、环境类别、设计使用年限与安全等级前后一致；梁柱墙板截面与配筋在平面/详图/表中一致；锚固、搭接写法；后浇带与施工缝做法 |
| 地下工程/轨道交通 | 抗渗等级与防水等级、抗浮水位与设防水位、围护结构与主体结构参数、变形缝与诱导缝做法、人防等级一致；围护平面与支撑平面的支撑道数、标高、间距（C10）；断面配筋与计算书（C11、C12）；地层参数取值（C13）；开挖与拆撑步序（C15） |
| 建筑 | 防火分区与耐火等级、门窗编号与门窗表、做法编号与做法表、标高体系、无障碍与疏散宽度在说明与平面中一致 |
| 给排水/暖通/电气 | 系统编号、设备编号与设备表、管径/规格与系统图一致；引用图集号与版本 |

## 一律不要报告

- 图签、签字、单位、人员、日期、出图章、图号目录与图签一致性（脱敏数据，范围外）。
- 缺少信息的猜测；“建议补充说明”这类泛泛意见。
- OCR 噪声、抽取顺序造成的异常；看不清的图面数值。
- 凭记忆中的规范、材料或工艺知识认定“应为某值”（图纸内没有相反文字就不算问题）。
- 自己补参数算出来的结论；对计算模型、软件选型的评价。
- 施工安全隐患、造价、方案优劣等非图纸文字可证明的判断。
