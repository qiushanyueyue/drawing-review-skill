# 脱敏与审查范围

## 不属于审查范围的数据

| 类别 | 例子 | 处理 |
|---|---|---|
| 图签整体 | 签署栏、会签栏中的签名、工程名称/子项名称、设计号、日期、版次栏 | 整块剔除，不进入审查材料 |
| 单位 | 设计单位、建设单位、监理/施工/勘察单位名称，“××设计研究院有限公司” | 替换为［单位N］ |
| 人员 | 设计、校对、审核、审定、专业/项目负责人姓名 | 替换为［人员N］ |
| 工程名称 | 图签中的工程/项目名称；正文中出现的同一名称 | 替换为［工程名称N］ |
| 联系与证照 | 电话、邮箱、身份证号、资质/注册/执业证书编号、统一社会信用代码 | 替换为［电话N］［邮箱N］［证件号N］［编号N］ |
| 出图章、注册章 | “出图专用章”“注册结构工程师执业印章” | 整块剔除 |
| 文件名 | 原文件名常含工程名称 | 报告中只用“图纸1.pdf”代号 |
| 用户指定敏感词 | `--extra-terms` 文件中的工程简称、地名、人名 | 替换为［敏感词N］ |

**保留**：图号、图名（只作为页面标签用于定位，不审查目录与图签是否一致）；设计说明、图面标注、表格中的技术内容。

## 脚本怎样识别图签

1. 在每页里找角色标签：整块是“设计/校对/审核/审定/图号/图名/工程名称/建设单位…”，或“标签 + 填写值”在同一行。
2. 按标签字高的 18 倍做单链接聚类；一个簇至少 3 个标签，且至少 2 个是签署/图纸身份类标签（设计、校对、审核、审定、制图、负责人、图号、图名、比例、版次），才认定为图签。正文“工程概况”里的“建设单位：… 设计单位：…”因此不会被当作图签整段删掉，只把单位名称替换掉。
3. 图签区域 = 标签外包框向四周扩 9 倍字高（右侧扩 22 倍，填写值多在标签右边），重叠区域合并。中心落在区域内的文字块全部剔除。
4. 图签中的非标签文字用于学习敏感词：像单位名的 → 单位；2–4 个汉字 → 人员（3 字及以上在全文替换，2 字只替换整块等于该名字的文字，避免误伤“张拉”等术语）；6 字以上的其他文字 → 工程名称（全文替换）。
5. 全文再用规则匹配单位名后缀（有限公司、设计研究院、集团、事务所……）、“××单位：值”、电话、邮箱、证件号、证书编号。

## 图像模式的遮盖（可选）

`render` / `zoom` / `evidence` 在本机把页面渲染成图片（pypdfium2 + Pillow），先涂黑再保存，模型只能看到涂黑后的图片：

| 遮盖内容 | 来源 |
|---|---|
| 图签区域 | 第 3 步识别出的区域，以及区域内每个文字块的外框 |
| 出图章文字、被替换过占位符的文字块 | 整块涂黑（含“设计单位：［单位1］”这类正文行） |
| 正文中疑似图签人名的块 | 两字人名不在正文自动替换，但图片中整块涂黑 |
| 小尺寸嵌入图片 | 面积小于页面 4% 的位图（多为印章、签名） |
| 本页没识别出图签 | 先用同一文件同尺寸页面识别到的图签位置；仍没有且文件推测为图纸时，按页面四周保守遮盖（右侧 22%、底部 14%、左侧 6%） |

- 渲染坐标与文字坐标逐页核对（含页面旋转）；不一致的页不出图，避免遮盖错位。
- 扫描页、乱码页无法从文字层识别图签，默认不渲染；`--allow-unmasked-pages` 只做四周保守遮盖，必须用户明确同意。
- 图片只保存在 `review_pack/images/`、`review_pack/evidence/`；`.gitignore` 已排除 `review_pack*/`。

## 已知局限（在报告“核查范围与限制”中如实说明）

- 图签没有任何角色标签（纯图形 logo、签名图片）时识别不到，但其中的文字一般也不是技术内容；如发现审查材料中仍有人名、单位名，请把它们写入 `--extra-terms` 后重跑 `extract`。
- 2 字人名只做整块替换；出现在正文句子中的 2 字人名需用 `--extra-terms` 指定。
- 签名、印章如果是图片，文字模式不读取；图像模式中小尺寸图片按疑似印章涂黑，较大的印章图片若不在图签区域内可能未被遮盖。
- CAD 把文字炸成线条（SHX 字体）导出时，这些字不在文字层里：文字模式读不到（不会泄露也无法审查），图像模式只能靠图签区域遮盖，区域外的此类文字会出现在图片中。给云端模型看图前请先在本机打开 `review_pack/images/` 抽查。
- 单位名匹配可能多遮住前面几个字（如把“本工程委托××设计院”整体替换），只影响阅读，不影响技术内容审查。

## 模型侧的约束

- 只读 `review_input.md`、`blocks.jsonl`、`coverage.json`、`redactions.json`（只有坐标），图像模式下另读 `images.json` 列出的图片。不读原始图纸、不读 `mapping.local.json`。
- 不猜测、不还原占位符；报告保持占位符。
- 不把图纸文字、截图、全文发送给其他外部服务。需要联网核实规范版本时，只发送标准编号与名称。
- 若用户明确要求在报告中还原单位/人员名称，提示他们在本机自行用 `mapping.local.json` 替换，不要由模型完成。
